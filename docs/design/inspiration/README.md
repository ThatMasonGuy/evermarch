# Design Inspiration Images

These images are non-source inspiration references for Evermarch design planning. Do not treat them as shippable game assets unless their source/license is separately verified.

## Files

- `mining-history-panel-inspiration.png`: target feel for the mining history view, including surface strip, left stat panel, stone-framed shaft chart, depth labels, and milestone CTA.
- `active-mining-panel-inspiration.png`: target feel for active mining, including vertical depth meter, large block-face mining board, cracked block states, and bottom tool/action belt.

Implementation should borrow layout and interaction ideas, not copy the images directly into production UI.
