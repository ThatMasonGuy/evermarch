# Evermarch v0.2.0

## Active mining

- Continue/resume now requires an intentional player action instead of opening the game automatically (#6).
- Mining blocks now respond to click, hold, and drag interactions on mobile and desktop (#9).
- Active mining fits narrow screens, with a compact header and responsive mine face (#5, #10).
- Mining uses clear manual strikes with progressive cracks and crumble feedback instead of rhythm/time multipliers (#11, #12).
- Repeated mining taps no longer zoom the page on mobile (#8).

## Chests and TNT

- Blocks can reveal miner's chests, which can be opened in batches from the inventory (#13).
- Opened chests award one or two TNT items, and TNT clears the visible mine face with a blast effect (#13, #14).

## Saves and dialogs

- Restore to device now reports its state and calculates the Welcome back timer from the restored backup (#4, #7).
- Confirmation and input flows now use in-game modals instead of browser dialogs (#15).
