# Evermarch v0.4.0

## Improvements

- Miner's chests now appear on average once every 5-6 active-mining layers, with fairer spawn rolls across both mine sizes (#21).
- Miner's chests now have their own blocky artwork, appear as full chest tiles in the mine, open in any batch size from the inventory sidebar, and reveal rewards in a cleaner animated result panel (#22).
- TNT now looks and feels like a real mining explosive, with dedicated item art and a compact fuse-to-blast effect that clears the mine face (#23).
