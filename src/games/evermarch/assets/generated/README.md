# Generated Evermarch assets

These original raster assets were generated for Evermarch with OpenAI's built-in image generation tool on 2026-07-13, then locally chroma-keyed, cropped, and downscaled to transparent 256 x 256 PNG files.

## Miner's chest

- `miners-chest-closed.png`: closed inventory and active-mining state.
- `miners-chest-open.png`: opened active-mining and reward-reveal state.
- Direction: chunky dark-oak mining chest, iron reinforcement, muted amber latch, voxel-adjacent materiality, no text, no copied game trade dress.
