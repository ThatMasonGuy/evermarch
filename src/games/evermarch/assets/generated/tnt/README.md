# Generated TNT assets

These original raster assets were generated for Evermarch with OpenAI's built-in image generation tool on 2026-07-13, then locally chroma-keyed, cropped, and downscaled to transparent 256 x 256 PNG files.

- `tnt-charge.png`: three-stick burgundy dynamite bundle with an iron band and lit braided fuse, used for inventory and active-mining controls.
- `mining-blast.png`: opaque blocky amber explosion with charcoal smoke blocks and stone debris, used only in the active-mining detonation effect.
- Direction: readable small silhouettes, voxel-adjacent materiality, no text, no cube shape, and no copied game trade dress.
